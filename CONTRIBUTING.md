# Contributing

We welcome focused contributions that improve verified political, geopolitical, macroeconomic, DeFi, and Stock Token intelligence.

## Before opening a pull request
1. Open or comment on an issue to align on scope.
2. Never commit credentials, private wallet data, production records, licensed provider payloads, or unverifiable claims.
3. Use UTC timestamps and synthetic fixtures.
4. Run the documented validation commands.
5. Add tests or sample validation when behavior changes.

By contributing, you agree that your contribution is licensed under Apache-2.0. For responsible disclosure or contributor support, contact support@usestormline.com.
